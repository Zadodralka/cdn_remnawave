# CDN Remnawave — настройка CDN-прокси для XHTTP (МТС / Yandex)

Репозиторий с рабочими инструкциями по проксированию VLESS/XHTTP-трафика Remnawave через российские CDN-провайдеры. Все схемы протестированы и подтверждены на боевых серверах.

## О чём этот репозиторий

Здесь собраны пошаговые инструкции по настройке связки **Remnawave + Xray (XHTTP) + CDN**, которая позволяет прятать VLESS-трафик за публичным CDN-доменом, снижая заметность и повышая устойчивость подключения к блокировкам.

На данный момент доступны инструкции для:

- **МТС CDN** (`mwscdn.ru`) — [`mts/`](./mts)
- **Yandex Cloud CDN** — [`yandex/`](./yandex)

Каждая инструкция покрывает полный путь настройки: архитектуру схемы, выпуск и проброс сертификата, конфигурацию inbound в Remnawave, настройку Host в панели, создание CDN-ресурса в личном кабинете провайдера, диагностику и полный сквозной тест туннеля.

## Важно

Каждая инструкция описывает конкретно опробованную рабочую конфигурацию под особенности своего CDN-провайдера (ограничения по HTTP-методам, поддержка WebSocket, обфускация и т.п.). Настройки одного провайдера не всегда переносимы на другого — используйте инструкцию, соответствующую выбранному CDN.
